# Show Bible
The viewer experiences: business pain -> dilemma -> insight -> audience request -> new tool -> realistic stress test -> proof -> caveat -> free gift -> request for next build.
Modes: BUILT (verified tested + available), PROTOTYPE (local demo, not hosted), DIAGNOSIS (concept only, no fake giveaway). Tone: short, natural Hebrew, business outcomes before technical jargon. No logo intro. Recurring line: אתם מבקשים. אני בונה. כולם מקבלים. One product and one test per episode. Success metrics: activated users and qualified business inquiries, not just views.
